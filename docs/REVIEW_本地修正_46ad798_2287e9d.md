## 二、逐条审核结论（审「该不该改 / 改得合理」）

### 1. 46ad798 — 订阅默认 UA 解耦到 clash-verge/v2.5.10（7 文件）
- **该不该改**：✅ 高。旧默认 `clash-verge/v0.1.0`（或绑定 `kAppVersion` 的 `0.x`）会被机场判为「客户端过旧」下发假节点。
- **改得合理**：✅ 优秀。`kSubscriptionCompatUserAgent` 落 `constants.h` 单一事实源；升号只改 `kAppVersion` 不动 UA；锚定 `v2.5.10` 与内置 mihomo 同代；`release_preflight.ps1` 正则硬性禁止回落 `0.x`；`test_net_http.cpp` 断言真实 `User-Agent` 头。配套设计文档质量高。
- **结论**：✅ 通过，无保留意见。

### 2. BUG-319/334/335/346 — 内核热更 PE 校验 + .staging 原子替换（core_updater.cpp +302）
- **该不该改**：✅ 必要。旧代码直接 `ofstream` 覆盖、无结构校验，损坏包会顶替运行内核。
- **改得合理**：✅。`inspect_mihomo_pe_binary` 完整解析 PE32+（MZ→PE→COFF Machine 0x8664→节表→OptionalHeader Magic 0x020B），**区分「结构损坏（Corrupted→删）」与「瞬态 I/O 不可用（IoUnavailable→保留回退 sidecar）」**；`flush_and_commit_staging` 先校验再 `MoveFileExW`（10 次重试）；BUG-335 快照回退 + BUG-346 `wait_cores_exit(3000)` 等内核释放句柄。
- **风险**：中（高价值防御）。⚠️ 已知限制：PE 校验硬编码 `0x8664`(x64)+最小 5MiB，将来 arm64 需扩展（非阻塞）。

### 3. BUG-324~326/329/330/331 — 服务模式三态判定 + ImagePath 解析 + 重入锁（service_mode.cpp +139 / service_runner）
- **该不该改**：✅ 必要。旧 `is_service_binary_valid` 的 ImagePath 解析只处理引号/`.exe` 两种情形，遇 `\??\` 前缀、`%env%`、尾空白误判。
- **改得合理**：✅。`extract_service_exe_from_image_path` 统一处理 `\??\`/`ExpandEnvironmentStringsW`/引号/`/exe` 边界/尾空白（单点真相）；`inspect_service_registration` 三态（NotInstalled/DisabledOrBroken/InstalledAndEnabled）；`service_operation_mutex()` 全局 `recursive_mutex` 串行化 install/uninstall/stop/start（BUG-352）。测试覆盖 `\??\`、双引号带参、无引号带参三态。
- **结论**：✅。

### 4. BUG-331 — 退出流程去 UAC（lifecycle.cpp +122 / app.cpp）【根因级修复】
- **该不该改**：✅✅ **非常必要**。旧 `h.stop_service` 正常退出走 `sc.exe stop (runas)` → 普通用户退出必弹 UAC 提权框，属明显 UX 缺陷。
- **改得合理**：✅。`h.stop_service = nullptr`：**正常退出彻底不走 sc stop**；改走无锁服务 IPC（`DELETE /clash/stop`）直停内核；服务模式位但 sidecar 停核后残活时补发 1500ms IPC `clash_stop` 释放 Wintun 网卡（模式漂移兜底）；仅「显式测试注入/显式禁用服务」才真正 sc stop。
- **风险**：中。🔍 **需确认**（见 §六.2）：`stop_service` 置空后，**NSIS 卸载段仍须正确 `sc delete` 服务**，不能依赖正常退出钩子。

### 5. BUG-323/327 — SSRF 防护补齐（ssrf.cpp +71 / net_http.cpp +184）
- **该不该改**：✅ 必要。旧代码漏判 IPv4-mapped IPv6 与单标签内网名；且存在 DNS Rebinding TOCTOU（预检过、连时解析到内网）。
- **改得合理**：✅。`ssrf.cpp` 新增 `::ffff:a.b.c.d` 映射回 IPv4 走 `ipv4_forbidden`、新增 `ip_string_forbidden` 解析 WinHTTP 带括号/端口/`%scope` 主机串、Domain 分支补齐 `.localhost/.local/.internal/.lan/.home.arpa`/169.254.*。`net_http.cpp` **用 `WINHTTP_OPTION_CONNECTION_INFO` 取实际连接目标 IP 做 SSRF 校验**（BUG-327 根因级修复），根除 TOCTOU；测试 `t_bug327_ssrf_guard_blocks_302_redirect_and_connect_rebinding` 验证 302 第二跳与 connect 期 rebinding 均被拦截、目标端口 0 连接。
- **结论**：✅ 安全级修复，纯校验增强不碰共享格式。

### 6. BUG-323 — 深链嵌套查询解析（scheme.cpp +138）
