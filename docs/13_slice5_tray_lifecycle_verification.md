## 1. 核心架构与实现要点

### 1.1 `WM_SIZING` 尺寸下限与防下移钳位算法
- **边界防御**：窗口逻辑尺寸不得低于 `MIN_WIDTH = 271px` 与 `MIN_HEIGHT = 126px`。
- **防止向下漂移算法（铁律）**：
  - 当用户拖动窗口顶部边框或上角（`WMSZ_TOP`, `WMSZ_TOPLEFT`, `WMSZ_TOPRIGHT`）向上缩小时，若高度落入小于 126px 的区间，**必须锁定 `top = bottom - minHeight`**。
  - 传统仅限制 `bottom` 会导致在拖动顶部时窗口整体向下“滑行”。本算法确保 `bottom` 锚点静止，精准纠正顶部坐标，彻底杜绝向下漂移。

### 1.2 极窄隐匿模式（10 秒空闲自续期定时器）
- **触发条件**：
  - 窗口逻辑宽度 $\le 285$px 且逻辑高度 $\le 126$px。
  - 持续 10 秒无鼠标移动、点击或键盘按键。
- **行为响应**：
  - 自动收起标题栏（32px），使整个客户区完整展示活跃节点与延迟指标。
  - 一旦捕获到 `WM_MOUSEMOVE`、`WM_KEYDOWN` 或窗口放大（高度 $> 126$px），立即解除隐匿模式，首帧还原标题栏。

### 1.3 静态系统托盘与三态图标（`InitTrayIcon`）
- 采用 Windows 原生 `Shell_NotifyIconW`（`NOTIFYICONDATAW`）与 `WM_TRAYICON = WM_USER + 200` 消息。
- 3 态提示文字：
  - 手动直连模式：`Clash Mini - 手动直连模式`
  - 系统代理开启：`Clash Mini - 系统代理运行中`
  - TUN 模式开启：`Clash Mini - TUN 模式运行中`
- 右键上下文菜单支持：“显示/隐藏主窗口”、“系统代理 (复选)”、“TUN 模式 (复选)”、“退出 Clash Mini”。双击直接还原并置顶主界面。

### 1.4 优雅退出 7 步生命周期防线（`GracefulExit`）
在接收到托盘“退出”、`WM_DESTROY` 或系统关机 `WM_QUERYENDSESSION` 时，按严格时序执行：
1. **隐藏界面**：立即调用 `ShowWindow(SW_HIDE)`，对用户呈现秒级退出感。
2. **几何状态即时同步**：调用 `SaveWindowStateImmediately()`，将最新的位置与尺寸即刻落盘。
3. **系统代理彻底复原**：调用 `SystemProxyManager::ResetAll()`，将注册表 `ProxyEnable` 归零，清空 `ProxyServer` 与 `AutoConfigURL`，并广播刷新 WinINET 缓存。
4. **终止健康探针**：调用 `HealthProbeService::Stop()`，安全注销后台定时探测线程。
5. **内核优雅终结与孤儿扫荡**：关闭 Job Object，触发 Windows 内核连带终结机制，随后调用 `KillAllOrphanCores()` 彻底扫除任何残留进程。
6. **注销托盘图标**：调用 `Shell_NotifyIconW(NIM_DELETE)` 释放托盘图标，防止鼠标滑过才消失的假托盘残留。
7. **投递退出消息**：`PostQuitMessage(0)`，安全退出主消息循环。
