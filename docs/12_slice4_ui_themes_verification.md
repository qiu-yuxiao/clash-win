## 1. 核心架构与实现要点

### 1.1 3D 实体拟物渲染管线（`D2DRenderer`）
- **物理倒角光影**：
  - 未按压状态：卡片顶部与左边绘制 `card_highlight`（高光），底部与右边绘制 `card_shadow`（倒角），形成自然 3D 凸起效果。
  - 按下状态：高光与倒角阴影对调反转，同时内部文本向下向右物理偏移 1 逻辑像素，模拟真实物理按键微位移与触感。
- **三段式工业分段切换开关**：
  - 绘制凹槽底板（Groove Track）与内凹阴影。
  - 选中的分段凸起呈 3D 实体按键，并附带 2px 品牌激活指示光条。
- **双控制滑块（Sliders）**：
  - 导轨槽带内部物理阴影，激活进度条填入主题强调色。
  - 3D 滑动手柄（Knob）带外圈高光边，支持鼠标悬停、拖拽与实时数值计算。

### 1.2 6 套特色皮肤与双控制滑块定义（`ThemeManager`）

| 皮肤标识 | 商业名称 | 视觉风格与调色 | 滑块 1 标签 | 滑块 2 标签 |
| :--- | :--- | :--- | :--- | :--- |
| `retro-3d` | **Trump-3D** | 经典实体象牙白/温润复古灰，物理凸凹按压，复古橘金强调 | `Depth` | `Vibrancy` |
| `original` | **Original** | 原版深灰科技质感 + Verge 科技蓝高光与深色倒角 | `Radius` | `Accent` |
| `modern` | **Modern** | 现代极简冷黑 + 锐利倒角边缘，高对比度 | `Contrast` | `Glow` |
| `frosted` | **Frosted** | 磨砂拟物实体 + 柔和光影边，清透质感 | `Blur` | `Saturation` |
| `cyberpunk` | **Cyberpunk** | 赛博朋克深空黑 + 霓虹青绿高光与品红电光底边 | `Neon` | `Scanline` |
| `monochrome` | **Monochrome** | 水墨工业黑白单色 + 高对比度硬朗实体边框 | `Intensity` | `Grain` |

### 1.3 宽窗（>285px）双栏排版与活跃连接监控面板
- 窗口内容宽度 $> 285$px 时自动启动双栏遮挡式排版：
  - 左侧：节点列表与切换。
  - 右侧：活跃连接观测表格，支持列式展示 `目标域名/IP`、`PROXY/DIRECT 路由链` 与 `实时吞吐速率`。
  - 顶部挂载「✕ 断开所有连接」控制按钮，直连 Mihomo `DELETE /connections`。
- 窄窗（$\le 285$px）自动卸载连接面板与关闭轮询定时器，杜绝后台 CPU 浪费。
