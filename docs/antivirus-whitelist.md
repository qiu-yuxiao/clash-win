# 安全软件（360 等）与 Clash Win 相容说明

> 本文与随包《`轻量模式防误杀指南.txt`》（由 App 内「帮助菜单 → 🛡️ 轻量模式防误杀指南」直接打开）配合说明，供仓库/Wiki 读者查阅。

## 一、为什么 Clash Win 会被安全软件清理？

Clash Win 需要在后台常驻托盘并拉起独立代理内核子进程（`win-mihomo.exe`）接管网络；在关闭主窗口进入「轻量模式」后，Direct2D 渲染表面与非必要 UI 资源会被释放，仅保留极简的托盘与后台进程继续转发流量。

这种「无可见主窗口但仍有后台代理子进程长期运行」的行为特征，容易被 360 等安全软件的启发式扫描或「清理加速」规则**误判为关窗残留进程**，进而连带中止主程序或内核，导致托盘图标消失与网络中断。

这是安全软件的误判——Clash Win 是开源软件，全部代码公开可查，没有任何隐蔽行为。

## 二、加入信任区（白名单）有什么好处？

将 Clash Win 加入 360 的「信任区 / 白名单」后：

- 托盘图标稳定常驻，轻量模式下也不会再消失；
- 代理内核（`win-mihomo.exe`）与系统服务通道稳定常驻，断网恢复与切换更可靠；
- 不会再弹出针对 Clash Win 的拦截提示或「已清理」通知。

## 三、可以不加白名单吗？

**完全可以不加，这是你的自由选择：**

- 没有安装 360，或所用安全软件并未拦截 Clash Win——无需任何操作；
- 即使正在使用 360，不加白名单也不影响核心代理功能：只要你主动打开 Clash Win，它就能正常工作。

## 四、不加入白名单会怎样？

如果你在使用 360 且未加入信任区，可能出现：

- 托盘图标被 360 的「清理加速」误杀而消失（轻量模式下尤其明显）；
- 托盘图标或 `win-mihomo.exe` 在轻量模式下被误杀中止后，需要你手动重新打开 Clash Win。

以上现象均为 360 拦截所致，重新打开 Clash Win 即可恢复，**不是程序损坏**。

## 五、如何加入 360 白名单 / 防止后台清理？

1. **常规信任区**：打开 360 安全卫士 →「木马防火墙 / 信任与防护」→「信任区」→ 添加 Clash Win 安装目录（默认位于 `C:\Program Files\Clash Win\`），或添加该目录下的 `clash-win.exe` 与 `win-mihomo.exe`。
2. **后台性能引擎根治白名单**（`BUG-398`，详见安装包根目录 `轻量模式防误杀指南.txt`）：
   - 方案一：开启「静默启动」，避免主窗口露出被清理规则标记；
   - 方案二：在 Windows 安全模式下将 `clash-win.exe`、`clash win_0`、`win-mihomo.exe` 等规则写入 `C:\Program Files (x86)\360\360Safe\netmon\` 下的 `whiteinternal.ini`、`useroptm2.ini` 与 `useroptm_game2.ini`。

不同版本 360 的入口名称略有差异，可在其设置中搜索「信任区」或「白名单」。

## 六、技术背景（面向开发者）

- Clash Win（同步至 Clash Mini v3.5.10）仅采用标准托盘驻留策略（关闭主窗口隐藏至托盘并释放 D2D 渲染资源，退出时清理子进程/关闭状态），已彻底移除伴生看门狗 / `1×1` 隐形哨兵窗口 / `Breakaway` 等反误杀进程机制，避免不必要的安全软件误报叠加；
- 将 `clash-win.exe` 与 `win-mihomo.exe` 加入安全软件信任区或底层清理白名单属于**环境配置**，是防误杀的唯一根因解，代码层无法替代；
- App 不修改、不绕过任何安全软件配置，仅提供随包文本文档说明并在诊断包状态检测中只读检查上述 `.ini` 覆盖状态。
